# Source Verification Checklist

Every source used anywhere in this skill, with its status. No number reaches a printed page, a client sheet, or a pitch until its row here reads "verified on [date]" by someone who opened the page. Most rows were retrieved by web search from an environment that could not open the pages, so their status is "retrieved, not read at source."

## How to verify in 30 minutes

1. Open each URL marked "not read at source." Find the number the file quotes.
2. If it matches, write "verified on [date]" in the status column and initial.
3. If it has changed, update the number and the date in every file that uses it (the "used in" column), or delete the number.
4. If the page is gone, delete the number from every file that uses it and note "source gone" here.
5. Do the government and research-firm rows first; they carry the most weight.
