# Source Library (local-service-launch)

All local-service skills share one source library. It lives at `../../local-service-sales-page/references/source-library.md`. Do not duplicate entries here; add new sources there so every local-service skill reads the same tiers, dates, and verification status.

The **Statistics to refuse** list also lives in the shared library. Check it before quoting any figure. A statistic on that list is never repeated as fact, even with a caveat.

## How to cite

- Use the entry format from the shared library: `- Title: URL (tier; date; fetched | snippet-confirmed, re-verify)`.
- Every load-bearing number in a launch artifact carries a source URL, tier, and date, or is labeled judgment.
- Vendor prices are never fixed. Write "vendor-reported; verify at signup."

This file is guidance, not legal advice. For compliance sources, read `compliance-floor.md` in this directory and consult counsel licensed in the business's state.
